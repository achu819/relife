# ReLife – Give Everything a Second Life

A responsive, frontend-only sustainability website built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Deploy on Vercel by importing this repository. Vercel detects Vite automatically; use `npm run build` as the build command and `dist` as the output directory.

All impact numbers shown on the site are illustrative demo statistics. The Get Started form is frontend-only and does not send or store submissions.
